3
FSRS 算法层 — 间隔重复核心
让每张卡片有独立的记忆曲线，科学安排复习时间
记忆参数 (Memory)
difficulty 0~10 · stability 掌握度 · retrievability 可回忆概率
4 档评分 (grade)
Again=1 忘记 · Hard=2 困难 · Good=3 良好 · Easy=4 简单
下次间隔 (interval)
由 FSRS 根据当前记忆参数 + 评分动态算出，不是固定值
① 用户评分
Again / Hard / Good / Easy
② FSRS 计算
更新 stability / difficulty / retrievability
③ 计算 interval
Good → 7天, Again → 1天, Easy → 15天
④ 写回 Dexie
due 日期更新，下次复习自动进入队列
Dexie 链式查询 / 写入
4

Dexie.js

为什么不选 localStorage?
只有 5MB，只能存字符串。IndexedDB 无上限，存对象/二进制/视频都 OK

💡 核心闭环跑通后的效果

1. 写一张知识点 → Dexie 自动分配 stability=0 新卡记录
2. 复习页只显示 due <= today 的卡片
3. 你点 Good → FSRS 算出 interval=7 → due = now + 7天
4. 再次打开应用，卡片不会再出现在复习队列，直到 7 天后自动出现
5. 成就系统从 fsrs 表聚合数据，解锁「连续 7 天」「掌握 50 个」等勋章
6. **全程无后端，纯前端，刷新数据不丢**
